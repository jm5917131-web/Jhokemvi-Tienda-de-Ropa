Jhokemvi - Tienda de Ropa

Descripción

Jhokemvi es una página web creada como proyecto de pre-entrega para mostrar una tienda de ropa ficticia.

La página cuenta con diferentes secciones, como inicio, productos, reseñas y contacto.

Tecnologías utilizadas

HTML5
CSS3
Google Fonts
Flexbox
CSS Grid
Media Queries

Objetivo

El objetivo del proyecto es aplicar los conocimientos aprendidos sobre desarrollo web, creando una página estructurada, responsiva y fácil de navegar.
